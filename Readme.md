# RESTful API с Swagger UI, миграциями и загрузкой файлов

**Бэкенд для административной панели базы отдыха**
Автор: Юлия Вовк | [GitHub @yulya-vovk](https://github.com/yulya-vovk)

## 🚀 Описание
Этот проект — полноценная **административная панель (админка)**, реализованная как REST API на Node.js, работающее с PostgreSQL через Docker.

API позволяет управлять:

- Услугами (/services)
- Галереей изображений (/gallery)
- Документами (/docs)
- Контактной информацией (/contacts)
- Документация доступна через **Swagger UI**, что делает API удобным для тестирования и интеграции с фронтендом.

## 🛠️ Технологии

| Компонент       | Назначение |
|-----------------|-----------|
| Node.js         | Серверная логика |
| Express         | Web-фреймворк |
| TypeScript      | Язык разработки |
| PostgreSQL      | Хранение данных |
| Docker          | Запуск БД в контейнере |
| db-migrate      | Система миграций |
| Swagger UI      | Интерактивная документация |
| Multer          | Загрузка файлов |
| CORS            | Поддержка кросс-доменных запросов |

##  🔧 Как запустить

1. **Установите зависимости**
```bash
npm install

2. **Запустите PostgreSQL через Docker**
```bash
docker compose up -d

3. **Примените миграции**
```bash
npx db-migrate up

4. **Запустите сервер**
```bash
npm run dev

5. **Откройте в браузере**
Главная страница: http://localhost:8080
Swagger UI: http://localhost:8080/swagger

📝 Возможности API

|Эндпоинт   | Метод                  | Описание |
|-----------|------------------------|-----------|
| /services | GET, POST, PUT, DELETE | Управление услугами |
| /gallery  | GET, POST, PUT, DELETE | Загрузка и скрытие фото |
| /docs     | GET, POST, PUT, DELETE | Работа с юридическими документами |
| /contacts | GET, PUT               | Обновление контактной информации |

Все эндпоинты задокументированы в Swagger UI с примерами запросов и ответов.

🔐 Безопасность
Все запросы к POST, PUT, DELETE можно защищать через JWT (реализуется отдельно)
CORS разрешён только для http://localhost:3000 (фронтенд)
Файлы сохраняются в папку uploads/ с уникальными именами

📦 Переменные окружения
Создайте файл .env

DATABASE_URL=postgresql://admin:adminpass@localhost:5432/admin_api
PORT=8080

📸 Пример использования
Добавить документ:

```bash
curl -X POST http://localhost:8080/docs \
  -H "Content-Type: multipart/form-data" \
  -F "files=@Договор.pdf"

Обновить контакты:

PUT /contacts
{
  "address": "г. Тюмень",
  "phone": "79991234567",
  "email": "info@resort.ru"
}
